# The Hidden Quotient Behind the Multiplication Representation

A short expository note in measure theory and functional analysis. The identification of a bounded measurable function $f$ with its multiplication operator $M_f$ on $L^2(X,\mu)$ is not primitive — it is the result of a quotient by the locally null functions. Making that quotient explicit yields the correct operator-norm identity $\|M_f\| = \|f\|_{\infty,\mathrm{loc}}$, identifies the quotient algebra as $L^\infty(\mu_{\mathrm{sf}})$ of the semifinite reduction, and shows that the multiplication representation theorem, the $L^1$–$L^\infty$ duality, the maximal abelian von Neumann property, and the Radon–Nikodym theorem are equivalent faces of a single localizability condition.
