# Changes in this release

- Added the geometry corpus review, including definitions, theorem scope, family comparisons, concrete repairs and a unified observation/provenance architecture.
- Added readable and machine-readable source registers with explicit review coverage and source distinctions.
- Recomputed retained session-transition, returned-record and name-register metrics; recorded input hashes.
- Included a portable verification script accepting explicit source-file arguments.
- Prepared copies of all four deliverables for GitHub. Local machine paths were replaced by `external-source:<filename>` labels; the source register explains these labels. JSON formatting was normalized. The review findings, evidence counts, source URLs and source hashes were preserved.
- Added this README, changelog and package checksums. Original Drive corpus documents and raw research inputs were not changed or included.

Mathematical results, observations, hypotheses and normative commitments retain separate status. This release does not turn missing provenance into a mechanism finding.
